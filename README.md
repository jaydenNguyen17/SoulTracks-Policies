# SoulTracks Policies

Public Terms of Use, Privacy Policy, and Community Guidelines for the SoulTracks controlled beta.

The site contains no JavaScript, analytics, forms, images, embeds, or third-party subresources. Policy pages are generated from the reviewed application policy manifest:

```powershell
node tools/generate-pages.mjs C:\path\to\SoulTracks\src\features\auth\policies.json
node tools/validate-pages.mjs C:\path\to\SoulTracks\src\features\auth\policies.json
```
